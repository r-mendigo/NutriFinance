# 💰 NutriFinance

NutriFinance is a personal finance and budgeting application designed to help users build healthier financial habits through simple budgeting, expense tracking, and meaningful financial insights.

## 🎯 Purpose

The goal of NutriFinance is to make personal finance easier to understand by combining organized financial tracking with modern productivity features.

## ✨ Current Features

- Budget management
- Expense tracking
- Income monitoring
- Financial summaries
- AI-assisted financial insights
- Clean and intuitive interface

## 🚀 Future Roadmap

- Savings goal tracking
- Investment dashboard
- Bill reminders
- Financial reports and analytics
- Enhanced AI-powered recommendations
